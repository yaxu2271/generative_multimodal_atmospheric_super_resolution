# Data and model inputs

This repository contains code and experiment metadata only. It does not
redistribute observation data, ERA5 fields, trained weights, or posterior
samples.

## Public data providers

- **IGRA radiosondes:** NOAA National Centers for Environmental Information,
  Integrated Global Radiosonde Archive.
- **MADIS aircraft observations:** NOAA Meteorological Assimilation Data
  Ingest System, Aircraft Based Observations.
- **MADIS surface observations:** NOAA MADIS METAR products.
- **ERA5:** Copernicus Climate Data Store.

Users are responsible for complying with the terms and access requirements of
each provider.

## Expected processed inputs

The public wrappers expect the following local inputs:

1. An ERA5 root containing the fields referenced by the Hydra dataset
   configuration, plus `normalize_mean.npz`, `normalize_std.npz`, `lat.npy`,
   and `lon.npy`.
2. A pickle containing IGRA locations and standardized values at the analysis
   indices used by the sampler.
3. Processed MADIS aircraft NPZ files generated by
   `scripts/preprocess_madis_aircraft_13var_npz.py`.
4. Processed MADIS METAR NPZ files generated by
   `scripts/preprocess_madis_metar_13var_npz.py`.
5. The pretrained 13-variable atmospheric diffusion checkpoint and its Hydra
   configuration.

The paper uses aircraft reports from ACARS direct, MDCRS/ARINC, and Canadian
AMDAR, assigns observations within 25 hPa of the 500 and 850 hPa levels, and
uses equal-cell residual counting. Surface observations constrain 2 m
temperature and 10 m horizontal winds within the paper's CONUS domain.
